# Retro*-190 다단계 경로 탐색

같은 190개 표적, 구매 가능 물질 23,081,629개, 저자 배포 비용 추정기 및 MEEA*-PC 탐색을 사용했다. 확장마다 상위 템플릿 50개를 적용했고, 표적당 최대 100회 정책 호출, 선택당 리프 샘플링 100회, c_puct 4.0을 적용했다. CPU에서 네 정책을 비교했다.

완결 경로는 남은 모든 전구체를 구매 가능 물질 목록에서 찾은 경우다. 두 단계 이상 완결 경로 수는 전체 190개 표적을 분모로 계산했다.

| 정책 | 완결 경로 / 190 | 2단계 이상 / 190 | 학습 중복 제외 완결 / 185 | 타임아웃 |
|---|---:|---:|---:|---:|
| Fingerprint MLP | 21/190 (11.05%) | 21/190 (11.05%) | 20/185 (10.81%) | 0 |
| Fingerprint Transformer | 10/190 (5.26%) | 10/190 (5.26%) | 10/185 (5.41%) | 0 |
| SMILES Transformer | 21/190 (11.05%) | 20/190 (10.53%) | 19/185 (10.27%) | 0 |
| SMILES Transformer + 결합 변화 보조 학습 | 13/190 (6.84%) | 12/190 (6.32%) | 11/185 (5.95%) | 0 |

원본 경로의 표적과 평가 목록 190개가 일치했다. 완결 경로의 고유 출발 물질 153개를 구매 가능 물질 CSV에서 재확인했다.
학습 중복 제외 열은 정책 학습 행의 생성물과 canonical SMILES가 일치한 표적 5개를 제외했다. 경로 내부 중간체의 학습 데이터 중복은 이 기준에 포함하지 않았다.

SMILES 보조 학습으로 새로 해결한 표적은 4개였고, 기본 SMILES 정책만 해결한 표적은 12개였다.
