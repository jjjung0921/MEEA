# SMILES 토큰 인코더 비교

2026-11-21 작성. v1, 사용자 승인. 단일 단계 반응 규칙 분류 파일럿.

## 질문과 비교

같은 SMILES 토큰과 같은 반응 규칙을 주었을 때 시퀀스 인코더 선택이 후보 50개 안에 정답을 포함하는 비율을 바꾸는지 본다. 기존 SMILES Transformer와 SMILES를 앞뒤로 읽는 상태공간모델(SSM)을 새로 학습한다. 기존 반응 가지 SSM은 후보 재정렬용이어서 이 비교의 기준선으로 쓸 수 없다. 이 실험의 범위는 인코더 비교까지이며 순서 활용 능력과 BACE 경로 성공률은 별도의 검증이 필요하다.

## 데이터와 조건

기존 학습 35,634건과 검증 8,903건의 파일 해시, 규칙 ID와 표본 순서를 기록한다. 학습 분할로 만든 공통 어휘, 같은 토큰화와 길이 제한, 패딩 마스크, 양쪽 모델의 동일한 masked mean pooling과 분류 헤드를 사용한다. 따라서 Transformer도 같은 조건으로 재학습한다. 기존 벤치마크 학습 설정을 공통 적용하고 시드 0, 동일 배치 순서, 최대 30 epoch, 마지막 epoch를 비교한다. 파라미터 수, 학습 시간, 잘린 입력의 비율을 보고한다. 단일 시드와 기존 검증셋으로 얻은 탐색적 결과로 해석한다.

## 구현과 검증

Claude가 기존 학습 진입점과 토크나이저를 재사용한다. 양방향 대각 선형 SSM은 패딩에서 상태가 갱신되지 않도록 하고, 양쪽 방향에서 얻은 토큰 출력을 결합한다. 기존 PyTorch로 소규모 배치에서 출력 차원, 패딩 불변성, 유한한 손실과 gradient를 확인한다. 속도가 병목이면 측정된 배치 시간으로 전체 소요 시간을 추정해 보고하고, 데이터를 임의로 줄여 얻은 점수를 전체 결과로 보고하지 않는다. 가중치는 별도 출력 폴더에 저장한다. 자체 장비만 사용한다.

## 평가와 산출물

주 지표는 평가 반응별 정답 규칙의 Top-50 포함률이다. 보조 지표는 Top-1 정확도와 두 모델 중 하나만 성공한 항목 수다. 같은 반응에 대한 성공 여부를 짝지어 차이를 계산한다. 실행 설정, 체크포인트와 어휘표, 항목별 정답 순위, 결과 요약을 보관한다. 분할 또는 규칙 ID 불일치, 비정상 손실, 패딩 검증 실패가 있으면 점수 비교를 보류한다. 모델별 독립 튜닝과 다단계 경로 탐색은 이번 실행 범위 밖이다.
